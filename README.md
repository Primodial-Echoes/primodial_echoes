# [INIT] Project Kickoff: Primordial Echoes 🌌👁️

## 概述 / Overview
Welcome to the core repository for **Primordial Echoes**. This issue tracks the foundational setup, branding, repo configuration, and initial concept phase for our horror game studio.

## 🎯 Studio Vision
Primordial Echoes develops immersive, narrative-driven horror games that explore cosmic insignificance, psychological dread, and forgotten mythologies. 

---

### Phase 1: Core Setup & Governance
- [ ] Define studio charter and core values.
- [ ] Set up organization structure and team roles (Engineering, Narrative, Audio, Art).
- [ ] Establish communication channels (Discord, Project Management boards).
- [ ] Configure repository permissions and branch protection rules (`main`, `develop`).

### Phase 2: Branding & Identity
- [ ] Finalize studio logo and visual style guide (dark, atmospheric, monochromatic tones).
- [ ] Register official domain and social media handles.
- [ ] Draft a basic press kit and one-pager.

### Phase 3: First Project Incubation (Codename: Project Void)
- [ ] Schedule initial pitch meeting for the debut title.
- [ ] Outline core gameplay loop (e.g., audio-driven survival, sanity mechanics).
- [ ] Write initial 2-page GDD (Game Design Document) teaser.
- [ ] Set up prototype repository in the organization.
